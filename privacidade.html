Política de privacidade

Atualizada em 7 de novembro de 2026.

O Resumao Paineis é uma ferramenta interna, usada apenas pelos donos dos canais que a autorizam.

Dados acessados

Com a autorização do dono, pela tela de permissão do Google, a ferramenta usa as APIs do YouTube para ler informações do canal, como vídeos, comentários e números de audiência, e para responder comentários quando o dono aprova.

Como os dados são usados

Os dados servem somente para o dono acompanhar e melhorar os próprios canais. Ficam guardados nos computadores dos donos. Não são vendidos nem usados para publicidade.

Revogar o acesso

O dono pode retirar a permissão a qualquer momento em myaccount.google.com/permissions e pedir a exclusão dos dados pelo e-mail abaixo.

A ferramenta usa os serviços de API do YouTube. Veja a Política de Privacidade do Google.
